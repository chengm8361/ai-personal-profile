## 关键决策

- **保真优先**：保留原始表述，不过度改写、不脑补缺失信息。
- **隐私脱敏**：不输出证件号、联系方式、账号等敏感数据。
- **一致性优先于个性化**：宁可按统一模板机械输出，也不让各 AI 工具自行发挥风格。
- **可追溯**：每次输出后说明覆盖范围，让缺口可见，而不是被格式掩盖。
- 推送兜底方案：`git push` 直连失败时，改用 GitHub Git Data API（blobs → trees → commits → PATCH refs）完成推送。

## 环境备注（有长期价值）

- 本机 `git push` 到 github.com 偶发连接重置（`Connection was reset`），但 curl 访问 github.com / api.github.com 正常——git 的 HTTP 栈与 curl 行为不一致，排障时需分开验证。
- API 创建 commit 的 message 不保留结尾换行，导致与本地 `git commit` 的 sha 不同；可用 `git hash-object -t commit -w` 在本地重建同字节对象后 `update-ref` 对齐。
- 凭据用 `git credential fill`（host=github.com）获取；origin 用户名必须是 `chengm8361`（`x-access-token` 形式会认证失败）。
