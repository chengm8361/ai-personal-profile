## 3. 沟通风格偏好

## 版本记录

本仓库使用 Git 做完整版本管理，任何一次修改都可通过提交历史（commit history）追溯与回退。

| 日期 | 版本 | 变更说明 |
| --- | --- | --- |
| 2026-11-07 | v0.1 | 初始化仓库，建立六大章节基础结构 |

### 维护约定

- **每次修改都要提交**，提交信息使用 `类型: 说明` 格式，例如：
  - `docs: 补充工作习惯中的专注时段`
  - `feat: 新增「常用提示词」章节`
- **重要节点打标签**，例如 `git tag v0.2 -m "补充项目经验"`，便于快速回到某个稳定版本。
- **回退方式**：
  - 查看历史：`git log --oneline`
  - 撤销某次提交的改动：`git revert <commit-id>`
  - 整体回到某个版本：`git checkout v0.2`
